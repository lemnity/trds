# План: дизайн «Табло города» (T-031 + ключевые экраны T-032/T-033)

## Направление
Сайт TURDUS как городское табло отправлений: белый фон, чёрные линейки, швейцарская сетка,
один красный акцент (из афиш театра). Монохром как у логотипа; цвет приносят афиши спектаклей.
Шрифты: Fira Sans Extra Condensed (заголовки, верхний регистр; у Plex Condensed нет кириллицы в Google Fonts),
Plex Mono (даты/время/цены — табличные цифры), Plex Sans (текст). Кириллица, self-host через next/font.
Запоминающаяся деталь: даты на табло «перелистываются» split-flap при появлении (CSS; выключено при reduced-motion).
Метка формата у каждого показа: БАР / КВАРТИРА / ГОРОД / ЗАЛ — главное отличие театра (спектакли вне сцены).

## Контракт
- Пользователь: зритель с телефона ищет ближайший показ и переходит к билетам; первое — дата, название, место, цена.
- Главный экшен: «Купить билет» у показа.
- Вьюпорты: 390x844, 1440x900 (минимум 360px без горизонтального скролла).
- Доступность: семантическая таблица/список табло, focus-visible, клавиатура, контраст AA, reduced-motion.

## Состав
1. Токены и база: `src/styles/tokens.css`, `globals.css`, шрифты.
2. Read model `src/modules/shows` (без React): типы, ближайшие показы, группировка по месяцам, формат дат
   в часовом поясе театра; демо-источник данных до CMS (T-021). Unit-тесты (TDD).
3. Компоненты: SiteHeader/MobileMenu/SiteFooter, Board/BoardRow, VenueTag, SplitFlap, ShowMeta,
   PerformanceList, Button, EmptyState/ErrorState.
4. Страницы: `/` (ближайший показ + табло + форматы + корпоративы), `/afisha` (табло по месяцам, фильтр по формату),
   `/shows/[slug]` (афиша, мета, даты и билеты), loading/error/not-found.
5. Проверка: тесты, lint, typecheck, build, Pages export; скриншоты 390/1440 через Chrome DevTools;
   evidence JSON + check-evidence; ревью react + a11y агентами.
